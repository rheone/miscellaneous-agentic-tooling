Claude Code CLI Cheat Sheet

Command-line reference · Windows edition

1Starting Sessions

claudeStart interactive session
claude "query"Interactive with initial prompt
claude -p "query"Print mode — run and exit
claude -cContinue most recent conversation
claude -c -p "query"Continue in print mode
claude -r <session>Resume by ID or name
claude -n "name"Set a display name

2Print Mode Flags

-p, --print "query"Run query, print, exit
--output-format text|json|stream-jsonOutput format
--json-schema <schema>Validated JSON output
--max-turns <N>Limit agentic turns
--max-budget-usd <$>Max API spend
--no-session-persistenceDon't save session

3Pipeline & Automation

Get-Content file | claude -p "q"Pipe file content
claude --bare -p "query"Minimal mode (fast)
claude --init -p "query"Run setup hooks
claude --init-onlySetup hooks, then exit
claude --effort <level>low/medium/high/xhigh/max
claude --fallback-model <m>Comma-separated fallbacks

4Permission Modes

--permission-mode defaultManual — prompt each action
--permission-mode acceptEditsAuto-accept edits
--permission-mode planPlan only — no changes
--permission-mode autoAuto-decide by risk
--permission-mode bypassPermissionsSkip all prompts
--dangerously-skip-permissionsSame as bypassPermissions
--allowedTools "..."Skip prompts for these tools
--disallowedTools "..."Deny these tools
--tools "Bash,Edit,Read"Restrict available tools

5System Prompt

--system-prompt "text"Replace default prompt
--system-prompt-file <path>Load replacement from file
--append-system-prompt "text"Append to default
--append-system-prompt-file <path>Append from file

6Background & Daemon

claude --bg "task"Start background session
claude --bg --exec "cmd"Background shell job
claude agentsMonitor / dispatch sessions
claude agents --jsonList active as JSON
claude attach <id>Attach to background session
claude logs <id>Print recent output
claude stop <id>Stop a session
claude respawn <id>Restart session
claude daemon statusCheck supervisor state

7Authentication

claude auth loginSign in to Anthropic
claude auth login --consoleSign in with API key
claude auth login --ssoForce SSO
claude auth logoutLog out
claude auth statusAuth status as JSON
claude setup-tokenLong-lived OAuth token

8MCP & Plugins

claude mcpMCP server config
claude mcp login <name>OAuth for MCP server
claude mcp logout <name>Clear OAuth credentials
--mcp-config <path>Load MCP from JSON
--strict-mcp-configOnly MCP from --mcp-config
claude plugin install <name>Install a plugin

9Utilities

claude updateUpdate to latest
claude install <version>Install specific version
claude project purge <path>Delete project state
claude -w <name>Git worktree session
claude --cloud "task"Web session on claude.ai
claude --teleportResume web session locally
claude -vPrint version

10Key Flags

--model <alias|name>Set model
--agent <name>Specify custom agent
--add-dir <path>Additional directories
--chrome / --no-chromeChrome integration
--safe-modeDisable customizations
--debug "api,mcp"Debug with category filter
--verboseFull turn-by-turn output
--settings <file|json>Override settings
--fork-sessionFork on resume
--from-pr <number|url>Resume PR-linked session
--advisor <model>Server-side advisor
--ax-screen-readerScreen-reader output
--remote-controlEnable remote control

11Practical Examples

rem Quick question
claude -p "How do I sort a list in Python?"

rem Resume and continue work
claude -r auth-refactor "Finish the remaining tests"

rem Background investigation
claude --bg "Find the cause of the flaky test"

rem Pipe content + query
Get-Content package.json | claude -p "Suggest dependency updates"

rem Print mode with structured output
claude -p --output-format json "List all npm scripts" > scripts.json

rem Budget-limited automation
claude -p --max-budget-usd 2.00 "Fix all lint errors"

rem Bare mode for fast scripting
claude --bare -p "Count LOC in src/"

rem Safe mode to troubleshoot config issues
claude --safe-mode

rem With custom model and effort
claude -p --model claude-sonnet-5 --effort high "Review this PR"

rem Worktree for isolated changes
claude -w feature-auth

rem System prompt override
claude --system-prompt "You are a Python expert" -p "Review this script"
