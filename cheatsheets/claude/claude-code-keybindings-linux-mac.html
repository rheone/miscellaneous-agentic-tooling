14Platform Notes: macOS vs Linux

  • macOS: Option/Alt shortcuts (Alt+B, Alt+F, Alt+Y, and the model/thinking/fast-mode toggles) need Option acting as Meta:
    • iTerm2: Settings → Profiles → Keys → General → set Option key to "Esc+"
    • Apple Terminal: Settings → Profiles → Keyboard → check "Use Option as Meta Key"
    • VS Code: set "terminal.integrated.macOptionIsMeta": true
    As of v2.1.132, Option+T works without this. Cmd+Backspace maps natively to Ctrl+U. Paste image with Cmd+V (iTerm2). Cmd+click opens PR links.
  • Linux: Alt-based shortcuts work natively — same as Windows, no Meta config needed. Paste image with Ctrl+V. Ctrl+click opens PR links.
  • Both: Shift+Enter works natively in iTerm2, WezTerm, Ghostty, Kitty, Warp, and Apple Terminal. In VS Code, Cursor, Alacritty, or Zed, run /terminal-setup once.
