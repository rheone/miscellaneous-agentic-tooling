OpenCode CLI Cheat Sheet

Command-line reference · Linux / macOS edition

1Basic Usage

opencodeStart TUI in current directory
opencode <project-dir>Start TUI in a project
opencode run <message>Run non-interactive with a prompt
opencode -cContinue the last session
opencode -s <id>Continue a specific session
opencode --forkFork session when continuing

2Session Management

opencode session listList sessions (-n N, --format json)
opencode session delete <id>Delete a session
opencode export <id>Export session (--sanitize)
opencode import <file|url>Import from JSON or share URL
opencode statsToken/cost stats (--days, --models)

3Auth & Providers

opencode auth loginInteractive login
opencode auth login --provider <id>Login to specific provider
opencode auth listList authenticated providers
opencode auth logoutRemove stored credentials

4Models & Agents

opencode run -m <provider/model>Run with specific model
opencode modelsList available models
opencode models --refreshRefresh model cache
opencode agent listList available agents
opencode agent createCreate a new agent
opencode run --agent <name>Run with an agent
Agent create (non-interactive): opencode agent create --path <file> --description <text> --mode subagent --permissions read,edit

5MCP Management

opencode mcp addAdd an MCP server
opencode mcp listList configured servers
opencode mcp auth <name>OAuth login for MCP server
opencode mcp debug <name>Debug OAuth issues
opencode mcp logout <name>Remove OAuth credentials

6Server & Web Mode

opencode serveHeadless HTTP API server
opencode webServer with web interface
opencode attach <url>Attach TUI to backend server
Server flags: --port, --hostname, --mdns, --cors. Set OPENCODE_SERVER_PASSWORD for auth.

7GitHub & PRs

opencode github installInstall GitHub agent
opencode github runRun GitHub agent
opencode pr <number>Fetch PR branch and run

8Plugins

opencode plugin <module>Install a plugin
opencode plug <module>Short alias
opencode plugin <module> -gInstall globally

9Utilities

opencode upgradeUpdate to latest version
opencode upgrade <version>Upgrade to specific version
opencode uninstallRemove OpenCode
opencode dbDatabase query
opencode db pathPrint database path
opencode debugTroubleshooting tools

10Global Flags

-h, --helpDisplay help
-v, --versionPrint version
--print-logsLogs to stderr
--log-level <level>DEBUG / INFO / WARN / ERROR
--pureRun without external plugins

11Key Env Vars

OPENCODE_CONFIGPath to config file
OPENCODE_CONFIG_DIRConfig directory path
OPENCODE_TUI_CONFIGTUI config file path
OPENCODE_SERVER_PASSWORDBasic auth for serve/web
OPENCODE_DISABLE_AUTOUPDATEDisable auto-update checks

12Practical Examples

# Quick question
opencode run "How do I sort a list in Python?"

# With file context
opencode run -f src/main.js "Find bugs in this file"

# Specific model
opencode run -m anthropic/claude-sonnet-5 "Explain this code"

# Continue last session non-interactively
opencode run -c "Finish what you started"

# Export thinking blocks
opencode run --thinking "Debug this crash"

# List recent sessions as JSON
opencode session list -n 10 --format json

# Start web interface
opencode web --port 8080 --hostname 0.0.0.0

# Auto-approve permissions (use with caution)
opencode run --auto "Install and configure ESLint"

# Headless server
export OPENCODE_SERVER_PASSWORD=mypass
opencode serve --port 4096
