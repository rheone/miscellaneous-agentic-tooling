Ctrl+X ↓Go to first child session
→Cycle to next child session

15Windows-Specific Notes

  • Terminal suspend is disabled by default on Windows — native Windows terminals don't support POSIX process suspend.
  • Undo gets an extra Ctrl+Z binding on Windows only, alongside Ctrl+- and Super+Z.
  • Shift+Enter for a newline doesn't work out of the box in some terminals. To enable it in Windows Terminal, edit %LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json: 
    // add to root-level "actions":
{ "command": { "action": "sendInput", "input": "\u001b[13;2u" },
  "id": "User.sendInput.ShiftEnterCustom" }

// add to root-level "keybindings":
{ "keys": "shift+enter", "id": "User.sendInput.ShiftEnterCustom" }
    Then restart Windows Terminal. Or just use Ctrl+Enter / Alt+Enter / Ctrl+J instead — no config needed.

16Customizing Keybinds

Edit tui.json in your OpenCode config directory. Example:

{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "leader": "ctrl+x",
    "session_new": "<leader>n"
  }
}
  • Multiple bindings: separate with commas, e.g. "ctrl+g,home"
  • Leader prefix: use <leader>, e.g. "<leader>n"
  • Disable a keybind: set its value to "none"
